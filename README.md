Sistema de Cadastro e Gerenciamento de Usuários em C

Este projeto é um sistema em linguagem C para gerenciamento de usuários, desenvolvido utilizando estruturas (`struct`), ponteiros e manipulação do buffer do console.

Cadastro: Leitura e armazenamento de dados (Nome, CPF, Endereço e Idade).
Pesquisa: Busca de usuários cadastrados por nome com `strcmp`.
Alteração: Edição dos dados de um usuário pelo índice do vetor.
Classificação: Ordenação em ordem alfabética (A-Z) utilizando o algoritmo **Bubble Sort**.
